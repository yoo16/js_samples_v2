CSRFトークン

                    
                    

                        バックエンドで発行されたトークンを、フォームから送信
                    

                


                

                    
                    

                


                

                    

                        
Cookie

                        
HttpOnly = true で JavaScript からアクセス不可

                    

                    

                        
Session

                        
    
                            
  • バックエンド（PHP）のセッションIDをブラウザの Cookie に保存
    • 
                            
  • ログイン後は、Cookie のセッションID でサーバー側のユーザーを認証
    • 
                        

                    

                    

                        
Fetch と Credentials

                        
    
                            
  • credentials で Cookie を送るかどうかを制御
    • 
                            
  • Same-Origin（同一オリジン）なら既定で Cookie 送信
    • 
                            
  • 別オリジンの場合、サーバー側の CORS（Access-Control-Allow-Origin）が必要
    •

使い方の流れ

                        
    
                            
  1. ページを開くと、左の「CSRFトークン」欄に自動でトークンが発行される
    2. 
                            
  2. 下のフォームにメールアドレス・パスワードを入力し「Login」を押す
    3. 
                            
  3. ログイン成功で、サーバー側のセッションIDが再発行され、CSRFトークンも更新される
    4. 
                            
  4. 「document.cookie を確認」を押し、セッションID（sid）がJavaScriptから見えないこと（HttpOnly）を確かめる
    5. 
                            
  5. 「/me」を押し、Cookieのセッションだけでログイン中のユーザー情報が取得できることを確かめる
    6. 
                            
  6. 「Logout」を押すとセッションが破棄され、以後「/me」を押すと401になることを確かめる
    7.
